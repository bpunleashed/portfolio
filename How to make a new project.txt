Na laptope zapneš server:

npm run dev 
 otvoríš http://localhost:4321 (alebo klikneš dole v pätičke na ⚙ Studio).
Zadáš názov, tagy, link na video/fotky 
 klikneš Save.
V termináli zadáš tri príkazy:

git add .
git commit -m "Add new project"
git push

Do 45 sekúnd je nový projekt publikovaný naživo na https://bpunleashed.github.io/portfolio/.
